#### Plataforma hiperconvergente con gobernanza normativa de grandes volúmenes de datos digitales para procesos de analítica, ciencia e inteligencia artificial agéntica

Objetivo: Diseñar e implementar una plataforma tecnológica hiperconvergente que consolide capacidades de almacenamiento, procesamiento, gobierno de datos y servicios analíticos, proporcionando un entorno escalable y seguro para la administración integral del ciclo de vida de los datos, el desarrollo de modelos de ciencia de datos y el despliegue de soluciones de inteligencia artificial agéntica alineadas con estándares normativos y buenas prácticas de gobernanza digital.
